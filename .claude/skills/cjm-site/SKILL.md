# CJM SITE — SKILL PRINCIPAL

## Objetivo

Este projeto é o site institucional e comercial da:

CJM – Limpeza de Coifas e Manutenção de Exaustores Ltda.

O site deve posicionar a CJM como empresa profissional especializada em:

- engenharia aplicada a sistemas de exaustão
- limpeza técnica de coifas
- limpeza de dutos
- limpeza de filtros
- manutenção de exaustores
- exaustores centrífugos
- damper corta-fogo
- lavadores de gases
- sistemas de ventilação
- manutenção preventiva
- inspeções
- relatórios técnicos e registros fotográficos

O objetivo principal do site é:

1. gerar pedidos de orçamento;
2. transmitir confiança;
3. demonstrar capacidade técnica;
4. apresentar serviços;
5. mostrar trabalhos executados;
6. melhorar presença no Google;
7. facilitar contato via WhatsApp.
